# Редактор структуры страницы

Страница собирается из блоков: текст, изображение, кнопка-ссылка. Блоки можно
добавлять, выбирать, редактировать, дублировать, удалять и переставлять
перетаскиванием. Есть режим предпросмотра без элементов редактирования.

Бекенда нет — мок в памяти с задержкой, версией документа и ответом 409.

## Стек

- Vite, React 19, TypeScript
- Zustand — состояние
- Feature-Sliced Design — архитектура
- shadcn на Base UI + Tailwind — интерфейс редактора
- SCSS-модули — собственные компоненты, включая канвас страницы
- @dnd-kit — перетаскивание
- Vitest, Testing Library — тесты

## Запуск

Node 22, pnpm 10. Минимальная ширина экрана — 900 px.

```bash
pnpm install
pnpm dev
```

| Команда            | Что делает        |
| ------------------ | ----------------- |
| `pnpm dev`         | дев-сервер        |
| `pnpm build`       | сборка в `dist`   |
| `pnpm typecheck`   | проверка типов    |
| `pnpm lint`        | eslint            |
| `pnpm lint:styles` | stylelint по SCSS |
| `pnpm test`        | тесты             |

## Структура

```
src/
├── app/                 точка входа, загрузка документа, глобальные стили
├── pages/editor/        трёхколоночная раскладка
├── widgets/             палитра, структура, инспектор, тулбар, предпросмотр, dev-панель
├── features/            правка блоков, выделение, реордер, история,
│                        синхронизация, разрешение конфликта, предпросмотр
├── entities/
│   ├── page-block/      типы блоков, рендер на канвасе, дифф
│   └── page-document/   документ, сторы, мок API
└── shared/              история, ошибки, константы, утилиты, компоненты shadcn
```

## История

- глубина 20, новое изменение после отмены очищает ветку повтора
- `Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y`
- блоки и история — в `documentStore`; статус сохранения, версия и конфликт — в
  `syncStore`; выделение и предпросмотр — в своих фичах. Служебные состояния в
  историю не попадают по топологии, а не по проверке в рантайме
- все изменения блоков идут через `applyBlocks`, мимо истории пути нет
- ввод в одно поле склеивается в один шаг: ключ склейки — «блок + поле», окно
  600 мс бездействия. Серия рвётся на `blur`, при смене блока и при отмене
- выравнивание, добавление, удаление, дублирование и реордер — всегда отдельный шаг
- `preventDefault` вызывается всегда, в том числе когда фокус в поле ввода: иначе
  браузер откатит содержимое поля своей историей и разойдётся с состоянием приложения
- сравнение по `event.code`, а не `event.key`: на русской раскладке `Ctrl+Z`
  приходит как «я»

Ядро — `shared/lib/history.ts`, чистый модуль без React; время передаётся параметром.

## Сохранение

Движок `features/document-sync` живёт вне React и подписан на `revision`.

- запрос через 700 мс после последнего изменения
- один запрос на документ; накопленные за время запроса правки уходят сразу
  после ответа, без повторного дебаунса
- сохранённой отмечается **отправленная** ревизия, а не текущая: набранное во
  время запроса остаётся грязным и уедет следующим запросом
- блоки из ответа сервера не применяются
- ошибка не запускает автоповтор — статус «Ошибка сохранения», повтор кнопкой
- статусы: Есть изменения, Сохраняется, Сохранено, Ошибка сохранения, Конфликт версий
- черновик пишется в `localStorage` на каждое изменение и удаляется после
  сохранения; при загрузке применяется поверх серверного документа, а если
  разошлись версии — через диалог конфликта

## Конфликт версий

409 замораживает цикл сохранения, но не редактор: документ остаётся
редактируемым, диалог закрывается и открывается заново из тулбара.

- обе версии показаны списками с номерами, расхождения помечены
- **принять серверную** — применяется через `applyBlocks`, то есть становится
  шагом истории: `Ctrl+Z` вернёт локальную версию
- **перезаписать своей** — базовая версия поднимается до серверной, запрос
  уходит с `force`

## Стили

Канвас объявляет свои токены `--page-*` на классе-обёртке и ничего не наследует
от редактора. Один и тот же `PageCanvas` рендерится в предпросмотре и в
мини-превью карточек. Границу сторожит eslint: `entities/page-block/ui/**` не
импортирует `shared/ui`.

## Проверка руками

Панель отладки в правом нижнем углу:

- **Изменить документ на сервере** — следующее сохранение упрётся в 409
- **Задержка ответа** — растянуть окно запроса и успеть поправить документ,
  пока он сохраняется
- **Вероятность ошибки** — состояние ошибки и кнопка повтора

Черновик: поправить что-нибудь и перезагрузить страницу в течение 700 мс.

## Тесты

```bash
pnpm test
```

`tests/scenarios/` — история с отменой и повтором, правка во время
выполняющегося сохранения, обе стратегии разрешения конфликта, изменение
порядка блоков без потери данных. Юнитами покрыты ядро истории и гонки
сохранения.

Реордер проверяется на уровне действия и результата, а не самого жеста
перетаскивания.
